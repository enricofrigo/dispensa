### How to Contribute

### 1. Reporting Bugs & Feature Requests

* Search existing Issues to make sure it hasn't been reported yet.
* Open a new Issue with a clear title and a detailed description of the bug or your proposal.

### 2. Submitting Translations (Localization)

* Locate the language files in the repository.
* Ensure your translations are accurate and follow the existing format.
* Keep context-specific terms (like AIC, GTIN, or DataMatrix) accurate to regional pharmaceutical standards.

### 3. Code Contributions

1. Fork the repository and create your branch from main.
2. Ensure your code is clean, documented, and follows standard formatting.
3. Write or update tests if applicable.
4. Open a Pull Request with a clear explanation of your changes.
